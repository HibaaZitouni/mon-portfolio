01 / Overview

Building a full e‑commerce experience

This project was born out of a real challenge: designing a complete online store from the ground up, handling everything from product catalog management to the final order confirmation email.

We chose Laravel for the backend for its elegant routing, ORM capabilities, and built‑in authentication scaffolding — allowing us to focus on business logic rather than boilerplate.

"A real e‑commerce isn't just a product list — it's a full journey, from browsing to checkout to delivery confirmation."
Next
02 / Architecture

MVC structure & database design

The application follows a strict MVC architecture powered by Laravel's Eloquent ORM. The database schema was carefully modeled with MySQL, covering Users, Products, Categories, Orders, and OrderItems with proper foreign key constraints.

We implemented a persistent cart system using session management and database sync, ensuring items survive browser restarts and are correctly tied to authenticated users.

Next
03 / Payment & Notifications

Card payment & email confirmation

The checkout flow handles two delivery modes — card payment and delivery on arrival. Each mode triggers a different order processing pipeline, with real‑time status updates stored in the database.

Post‑purchase, the system dispatches a formatted email confirmation using Laravel's Mail facade with custom Blade templates — including order summary, items, and expected delivery info.

04 / Retrospective

What we learned building this

Beyond the technical stack, this project taught us how to coordinate as a team — splitting responsibilities, handling merge conflicts, and maintaining a clean Git history across two developers.

We also deepened our understanding of security practices: CSRF protection, input sanitization, and authenticated route guarding — things that matter in any production web application.
